# 开关柜局部放电诊断手册

## 一、局部放电概述

局部放电（PD）是指高压电气设备绝缘内部在强电场作用下发生的非贯穿性放电现象。开关柜局放是影响设备绝缘寿命的重要因素。

### 局放指标参考值
| 局放水平 | 数值(pC) | 处理建议 |
|--------|---------|---------|
| 正常 | <20 | 无需处理 |
| 注意 | 20~30 | 加强监测 |
| 异常 | 30~50 | 安排检修 |
| 严重 | >50 | 尽快停运检修 |

## 二、开关柜局放常见原因

### 2.1 电晕放电
- 导体表面毛刺或不平整
- 接触不良导致电位悬浮
- 绝缘件表面污秽

### 2.2 内部气隙放电
- 浇注绝缘工艺缺陷
- 固体绝缘材料老化开裂
- 安装应力导致的微小裂纹

### 2.3 沿面放电
- 表面凝露或受潮
- 积灰积垢严重
- 绝缘材料老化

## 三、局放检测方法

### 3.1 TEV暂态地电压法
使用TEV传感器在开关柜金属外壳上测量局放产生的暂态地电压信号。

### 3.2 超声波法
使用超声波传感器检测局放产生的高频声波信号，可定位局放源位置。

### 3.3 UHF特高频法
通过内置UHF天线接收局放辐射的电磁波信号，灵敏度高。

## 四、局放异常处理流程

1. **确认告警**：核实局放数值和持续时间
2. **定位分析**：结合多种检测方法定位局放源
3. **趋势判断**：查看历史数据判断发展趋势
4. **风险评估**：根据局放水平和增长速率评估风险
5. **制定方案**：制定检修或更换方案
6. **实施处理**：按计划执行检修作业
7. **验证效果**：处理后复测确认效果
