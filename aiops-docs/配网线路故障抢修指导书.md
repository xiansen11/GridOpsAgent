# 配网线路故障抢修指导书

## 一、配网线路常见故障类型

### 1.1 短路故障
- 单相接地短路
- 两相短路
- 三相短路

### 1.2 断线故障
- 导线断裂
- 引线脱落
- 金具损坏

### 1.3 设备故障
- 断路器拒动/误动
- 隔离开关卡滞
- 避雷器击穿

## 二、故障快速定位方法

### 2.1 故障指示器法
利用线路安装的故障指示器指示故障区间。

### 2.2 配网自动化系统
通过SCADA系统和配电自动化终端（FTU/DTU）定位故障点。

### 2.3 巡视排查法
对疑似故障区段进行人工巡视检查。

## 三、抢修安全措施

### 3.1 停电作业安全
- 严格执行停电、验电、挂接地线程序
- 在工作地点设置安全围栏和警示标志
- 明确工作负责人和安全监护人

### 3.2 带电作业安全
- 使用合格的绝缘工具和个人防护装备
- 保持足够的安全距离
- 严禁同时接触两相导体

### 3.3 恢复送电条件
- 故障设备已修复或隔离
- 所有人员撤离至安全区域
- 拆除临时接地线和警示标志
- 确认线路具备送电条件

## 四、典型故障案例

### 案例1: 10kV线路单相接地故障
**现象**: 10kV母线A相电压为零，B/C相电压升高为线电压
**原因**: A相导线因树木触碰造成单相接地
**处理**: 巡线发现故障点，清除树木障碍，恢复送电

### 案例2: 变压器低压侧短路
**现象**: 变压器保护动作跳闸，低压侧有烧蚀痕迹
**原因**: 低压侧电缆头制作工艺不良导致相间短路
**处理**: 更换电缆头，测试合格后恢复送电
